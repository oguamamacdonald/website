# Macdonald Oguama Portfolio

Static GitHub Pages edition of Macdonald Oguama's professional portfolio.

The repository includes the complete client-facing website: home, services,
portfolio and credentials pages, together with the portrait, logo and styling.

## GitHub Pages

Publish from the `main` branch and the repository root. The site entry point is
`index.html` and `.nojekyll` keeps the generated static assets unchanged.

## Main pages

- `index.html`
- `services.html`
- `portfolio.html`
- `credentials.html`
